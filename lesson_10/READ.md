# Тестирование веб-калькулятора с помощью Selenium и Allure

Этот проект представляет собой автоматизированный тест веб-приложения **калькулятора с задержкой**, размещённого по адресу:  
[https://bonigarcia.dev/selenium-webdriver-java/slow-calculator.html]

Тест написан на **Python** с использованием:
- `selenium` — для управления браузером
- `pytest` — для запуска тестов
- `allure` — для генерации наглядного отчёта


## Как запустить тесты и сформировать отчёт
### 1. Установите необходимые пакеты

Убедитесь, что у вас установлен Python последней версии;
Установите Selenium: pip install selenium;
Установите Pytest: pip install pytest; Установите Allure: pip install allure-pytest; Установите Webdriver-manager: pip install Webdriver-manager.

### 2. Запустите тесты и укажите путь к каталогу результатов тестирования:

python -m pytest --alluredir allure-result

После выполнения теста в папке Allure появятся файлы с данными для отчёта.

## Как конвертировать результаты теста в отчет Allure
### 1. Установите Allure Report
Allure Report — это утилита. Она обрабатывает результаты тестирования и создает HTML-отчет.

Пользователи Windows: запустите в терминале VS Code команду:
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
Invoke-RestMethod -Uri https://get.scoop.sh | Invoke-Expression

Затем команду:
scoop install allure

Пользователи macOS: запустите в терминале VS Code команду:
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Затем команду:
brew install allure

### 2. Сгенерируйте и откройте отчёт
Введите команду ниже — сгенерируется отчет о тестах:
allure serve allure-result

Команда соберёт HTML-отчёт из данных в папке Allure;
Запустит локальный сервер;
Автоматически откроет отчёт в браузере;

В отчёте вы увидите:

Название и описание теста;
Пошаговое выполнение (with allure.step);
Статус прохождения;
Время выполнения;
Возможность добавить скриншоты.

## Описание теста: test_calculator()
Тест проверяет, что калькулятор корректно выполняет операцию сложения с учётом задержки.

Что делает тест:
Открывает страницу калькулятора;
Устанавливает задержку ввода: 45 секунд;
Вводит выражение: 7 + 8;
Нажимает кнопку =;
Ожидает появления результата;
Проверяет, что в поле отображается 15;

Особенности реализации:
Используется явное ожидание (WebDriverWait) — чтобы дождаться обновления результата после задержки;
Проверка идёт по точному совпадению текста в элементе .screen;
Тест помечен аннотациями Allure для лучшей читаемости отчёта.

Аннотации:
python
@allure.title('Работа калькулятора')
@allure.description('Вычисление суммы')
@allure.feature('READ')
@allure.severity('critical')

Шаги в отчёте:
Открыть калькулятор;
Задать задержку;
Ввести значения;
Сравнить результат.

## Описание теста: test_form()
Тест проверяет поведение формы при заполнении всех полей, кроме поля “Zip Code”, которое оставлено пустым. Цель — убедиться, что система корректно выделяет ошибочные поля (в данном случае — красным цветом фона).

Что делает тест:
Открывает страницу с формой;
Заполняет все поля, кроме Zip Code;
Проверяет цвет фона каждого поля:
    Красный — у поля с ошибкой (Zip);
    Зелёный — у всех остальных.

Особенности реализации:
Используется пользовательский класс Form;
Применяются явные ожидания (WebDriverWait) для надёжного взаимодействия с элементами;
Каждый шаг помечен с помощью with allure.step() для детализации в отчёте.

Аннотации Allure:
python
@allure.title('Заполнение формы')
@allure.description('Осталось пустое поле zip')
@allure.feature('CREATE')
@allure.severity('critical')

Эти аннотации позволяют:
Чётко идентифицировать тест в отчёте;
Группировать по функциональности (CREATE);
Определять приоритет (critical — высокий);
Упрощать анализ результатов при CI/CD;

Шаги теста в отчёте Allure
Открыть форму;
Внести заданные значения в поля (поле Zip оставлено пустым (''));
Проверить правильность отображения цвета фона полей:
    Для поля Zip ожидается цвет rgba(248, 215, 218, 1) (красный);
    Для всех остальных — rgba(209, 231, 221, 1) (зелёный).

    Sauce Labs Backpack;

    Фамилия: secret_name;
    Индекс: 444555.
